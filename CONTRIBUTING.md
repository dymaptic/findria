# Contributing to Findria

Thanks for your interest in contributing!

## Development setup

Follow the [Local Development Setup](README.md#local-development-setup) in the README.

## Before opening a pull request

- Run the unit tests: `npm test`
- Type check: `npx tsc --noEmit`
- Lint the files you changed: `npx eslint <files>`
- Add or update tests for behavior changes where practical.
- Keep pull requests focused; describe what changed and why.

Do not commit secrets, API keys, or `.env*` files.
