# Security Policy

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report vulnerabilities privately by either:

- Using GitHub private vulnerability reporting: go to the **Security** tab of
  [github.com/dymaptic/findria](https://github.com/dymaptic/findria) and choose **Report a vulnerability**, or
- Emailing [support@dymaptic.com](mailto:support@dymaptic.com) with "Findria security" in the subject.

Please include a description of the issue, steps to reproduce, and the potential impact. We will acknowledge
your report and keep you informed as we investigate and fix it.

## Scope

This policy covers the code in this repository. Issues in third-party dependencies should be reported to
their maintainers; issues in a fork or someone else's deployment should be reported to its operator.

## Bounty

dymaptic does not offer a bug bounty program for this project.
